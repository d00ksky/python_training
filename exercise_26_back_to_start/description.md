## Welcome to Day 1. Here is your first exercise:

### Zadanie

Napisz **funkcję w Pythonie**, która:

1. Przyjmuje **string** z imieniem i nazwiskiem użytkownika
   przykład: `"jan   kowalski"`
2. Zwraca **słownik** w postaci:

   ```python
   {
       "first_name": "Jan",
       "last_name": "Kowalski",
       "initials": "J.K."
   }
   ```
3. Wymagania:

   * ignoruj nadmiarowe spacje
   * popraw wielkość liter
   * nie używaj regexów
   * nie pisz kodu „na skróty”
   * ma być czytelnie i przewidywalnie

### Podpowiedź (jedna, więcej nie będzie)

Będziesz potrzebował:

* `str.strip`
* `str.split`
* indeksowania list
* `str.upper / str.capitalize`
